# 隔离前向演练

结构检查不能证明求职辅导有效。重要修改后，使用 `cases.json` 做独立前向演练，按 `rubric.md` 复核。

1. 每题建立独立临时数据目录，使用 `tests/fixtures/candidate.json` 的模拟材料或题目指定的空目录。
2. 执行者只接收技能目录、当前临时目录、用户请求和题目允许的输入文件，不接收 expect、anti_patterns 或评分。
3. 一轮只推进用户实际给出的内容。需要多轮的题使用预先固定的后续输入，不替用户编答案或授权。
4. 检查真实文件、版本备份、事实引用和工具返回。禁止访问真实求职材料或向招聘方发送消息。
5. 记录应答、产物、写入前后变化、限制及评分。执行模型与推理配置沿用宿主默认。

音频题覆盖不可辨认或不可处理时的真实降级，不把它视作所有宿主的语音识别认证。文档导出题使用宿主实际可用能力，检查文件和页面，能力不足时记录范围。
