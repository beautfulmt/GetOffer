# GetOffer

帮助校招生和实习求职者从真实经历出发写改简历、按目标 JD 定制、准备与模拟面试并逐题复盘的 Agent Skill。当前版本 v1.8.2。

## 功能

- 写改简历：从零散经历里问清个人贡献，写出一页基本写满的通用简历，每条经历有场景、本人动作和结果。
- JD 定制：分析匹配情况并直说结论，选择相关经历，生成岗位版简历；同方向海投时可以做一份方向版。
- 面试准备：按面试轮次准备自我介绍、可能追问、经历回答、求职动机和反问，以及 HR 面常问的到岗时间、薪资期望等问题。
- 模拟面试：按简历、JD 和面试轮次出题，题数接近真实面试，覆盖岗位需要的硬技能和软技能，每题追问有上限。可指定题数，默认整轮后点评，也可选一题一评；保存时另出一份网页版点评。
- 面试复盘：分析录音、文字稿或回忆稿，按这一轮的标准给整体评价。每个问题一张卡片，标出答得好、需补强或要重练，写明面试官想考察什么；左边是你的完整原答（含追问），右边逐条写出原话改成了什么、为什么，并说明下一轮怎么准备，确认新素材后回写简历。保存时出 Markdown 报告和一份可直接打开的网页版。

各模块共用经历库，保留通用版、方向版、各岗位版本和旧稿。目标岗位不限产品经理，默认中文，也支持英文材料。

写简历时材料不够会先问清再成稿。第一份简历先用一轮盘点有哪些经历，再每轮聊一段，一次给 4 到 6 个带示例的小问题，想到多少答多少。还没补充就想先看稿时，会给一份带空位的待补稿：每条按场景、动作、结果写全，缺的事实标成醒目的空位，补完就是投递稿。赶投递时先交现有事实能支持的版本，并说明哪里偏薄；确实只有这么多就如实写，不编造、不凑字。

面试准备、模拟和复盘按业务一面、二面、主管终面和 HR 面区分重点。不清楚是第几面时会问一次，说不清就按业务一面。

## 安装

完整技能位于 [`skills/get-offer/`](skills/get-offer/SKILL.md)。将整个目录放入所用工具支持的技能目录，保留 `references/`、`assets/`、`scripts/` 和 `agents/`。

macOS 或 Linux 可通过链接安装：

```sh
git clone https://github.com/beautfulmt/GetOffer.git "$HOME/GetOffer"
mkdir -p "$HOME/.codex/skills" "$HOME/.claude/skills"
ln -s "$HOME/GetOffer/skills/get-offer" "$HOME/.codex/skills/get-offer"
ln -s "$HOME/GetOffer/skills/get-offer" "$HOME/.claude/skills/get-offer"
```

目标已有同名目录或链接时，先备份再处理。按实际使用的工具选择对应安装位置。

## 使用

直接描述当前任务并提供已有材料，例如：

- “我没有实习，做过课程项目，帮我写第一份简历。”
- “按这份产品实习 JD 调整简历，缺什么也直接说。”
- “我要海投数据分析实习，按这三份 JD 做一份方向版。”
- “按这份简历和 JD 模拟一面，问完再统一点评。”
- “下周是 HR 面，帮我准备，再模拟一场。”
- “刚面完二面，没有录音，帮我按回忆复盘。”

## 文件与能力

个人材料默认保存在 `~/get-offer-data/`，也可指定位置；明确要求不保存时，只在对话中处理。简历只使用用户明确陈述或确认的事实。切回默认目录时也更新位置指针，方便下次接续。保存面试复盘时，默认隐去不必要的身份信息，只对明确敏感值做替换或概括，保留分析所需的事实与口径。

整份简历初稿默认直接提供 PDF，联系方式可以留空。正式投递版默认提供 PDF 和可编辑 Word。PDF 由自带脚本生成并核验，只需 Python 3.8+ 和本机的 Chrome、Edge 或 Chromium；面试报告网页版交付前也有脚本校验。文件导出和录音转写依赖所用工具的现有能力。技能不自带转写引擎，不要求 API Key；能力不足或样式降级时会说明实际完成情况，上传第三方转写前需要用户同意。没有录音时，可以按回忆写下问答来复盘。
