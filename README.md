# GetOffer

帮助校招生和实习求职者把真实经历讲清楚的 Agent Skill。当前版本：v1.0.0。

## 能做什么

| 模块 | 输入 | 交付 |
|---|---|---|
| 写改简历 | 零散经历或已有简历 | 经历库、通用简历、具体修改说明 |
| JD 定制 | 岗位描述与个人材料 | 匹配报告、目标版简历、差距与准备重点 |
| 面试准备 | JD、简历与经历库 | 可能追问、经历故事、自我介绍、逐轮模拟 |
| 面试复盘 | 面试录音或文字稿 | 每题的原答、问题、完整改进答法，以及可回写简历的素材 |

四个模块共用个人经历库。面试发现的新素材先确认，再用于下一版简历；通用版、公司版和旧版本分别保留。

## 怎么使用

可以直接提供当前任务和已有材料，不必从第一步重来。例如：

- “我没有实习，做过课程项目，帮我找能写进简历的内容。”
- “按这份数据分析实习 JD 调整简历，缺什么也直接说。”
- “基于这份简历模拟一面，每次问一题，等我回答。”
- “逐题复盘这段面试稿，给出完整改进答法，再列哪些内容可以补进简历。”

默认中文，也支持按实际岗位准备英文材料。目标岗位不限产品经理。技能帮助整理证据与练习，不保证匹配度、面试通过或录用结果。

## 安装

技能完整目录是 [`skills/get-offer/`](skills/get-offer/SKILL.md)，包含入口、参考、模板和可选界面元数据。将整个目录放入宿主支持的技能目录即可，不只复制一个 SKILL.md。

macOS 或 Linux 可以保留一份仓库，再用链接给两个宿主使用：

```sh
git clone https://github.com/beautfulmt/GetOffer.git "$HOME/GetOffer"
mkdir -p "$HOME/.codex/skills" "$HOME/.claude/skills"
ln -s "$HOME/GetOffer/skills/get-offer" "$HOME/.codex/skills/get-offer"
ln -s "$HOME/GetOffer/skills/get-offer" "$HOME/.claude/skills/get-offer"
```

目标已有同名技能时，先检查并备份，避免覆盖已有内容。其他宿主按其技能加载方式使用同一份 Markdown 资料。技能正文没有固定模型或私有工具依赖。

## 音频和文件能力

音频按“直接理解 → 已有本地转写或有音频工具的 Agent → 请用户提供文字稿”的顺序处理。缺少能力时如实说明；外部转写上传前需要用户同意。技能本身不捆绑语音识别引擎、不自动安装大模型，也不要求配置 API Key。

Word、PDF 使用宿主已有文档能力真正生成，并检查页面与文本；能力不足时交付实际可用格式。不同宿主的音频与文档能力需要分别核实。

## 事实与个人资料

- 简历只使用用户明确陈述或确认的事实；推算保存依据，缺数字时可以写真实产物与反馈。
- 教学允许使用明确标注的虚构示范，独立保存，不进入经历库或简历。
- JD 定制主要做经历选择、排序和准确表达，不把岗位要求变成个人已经具备的技能。
- 个人资料保存在用户选择的目录。当前目录属于技能或本仓库时，建议独立个人目录，例如 `~/get-offer-data/`。
- 仓库不收集简历、面试录音或联系方式；测试仅使用明确标注的模拟材料。

## 结构与校验

```text
skills/get-offer/
  SKILL.md
  references/       四个模块与真实性规则
  assets/           经历库、简历、匹配报告、准备和复盘模板
  agents/           可选的 Codex 界面元数据
tests/              包完整性检查与隔离前向演练
```

开发校验在仓库根目录运行，只需要 Python 标准库：

```sh
python3 -B -m unittest discover -s tests -v
```

结构检查覆盖文件和路由完整性；真实行为通过隔离的前向演练验证。每次重要修改应检查简历事实、JD 差距、逐题复盘、回写授权和能力不足时的真实降级。

v1.0.0 验收包含 5 项包检查和 13 个前向场景，均达到本次通过标准；真实生成的 Word/PDF 已检查 A4 单页、中文显示和原文一致性。有效人声转写、跨模型表现和原生 Word 跨机分页没有做普遍认证，详见[验收记录](tests/evals/results/2026-10-19.md)。
