# 模拟面试点评

- 岗位与目标级别：按 JD 填写
- 轮次：业务一面、二面、终面或 HR 面；按默认处理时注明
- 依据材料：简历版本、JD 来源、经历库
- 实际题数与反馈方式：核心题几道、追问几次，整轮统一点评或一题一评；用户指定的题数、时长或范围按需注明
- 跳过、未答或提前结束的题：实际列出，没有就删除

## 整体评价

按本轮的标准给一句话结论，说明距离要求还差什么。最突出的一两个优点，最要害的一两个问题及其对面试官判断的影响。不打分、不分等级，不预测录用结果。

## 逐题点评

### Q1：实际问题

- **考核点：**这题要看的素质或经历
- **你的回答：**引用原话或忠实概括，含追问与回答
- **好在哪：**具体做法
- **问题在哪：**直接点明，并指出原答对应的位置；知识题写明对错，拿不准的注明
- **改进答法：**直接回应题目、可自然说出口的完整回答；缺的事实单列，请用户补充
- **讲圆满：**有归属疑点时，说明怎样交代分工、补齐自己那部分、讲清对整体的理解；没有就删除

每道题都按需要展开，简单题保持简短，不用一份总体评价代替逐题点评。
