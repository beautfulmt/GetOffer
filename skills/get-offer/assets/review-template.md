# 面试逐题复盘

字段写法见 references/report-html.md 的“逐题点评”。

## 输入与评价基准

- 岗位、日期与轮次：轮次是推断的写明依据，按默认标准评的注明
- 评价基准：读取的 JD、投递简历版本与经历库；缺少时写明基准有限
- 材料来源：原音频、录音转写、用户文字稿或回忆稿
- 已覆盖问答：实际编号或可靠时间范围；合并或没计入的事务性问答
- 尚未覆盖、听不清或说话人待确认：明确列出
- 脱敏：实际替换的内容及对核验的影响；没有处理写无，保留原文的注明

## 整体评价

- **一句话结论：**
- **标签统计：**答得好 N 题、需补强 N 题、要重练 N 题
- **最突出的优点：**一两条，附题号
- **最要害的问题：**一两条，附题号和对判断的影响
- **先改这三题：**题号和为什么先改；全部答得好就删掉这一条
